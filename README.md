# МЕДИКА — сайт клиники семейной медицины

Готовый многостраничный сайт частной клиники: 10 страниц, адаптивная вёрстка, запись на приём, личный кабинет пациента, телемедицина и библиотека материалов. Чистый HTML + CSS + JavaScript, без сборки и зависимостей.

**Эта папка самодостаточна.** Сайт лежит в корне, исходники — в `_sources`.

## Открыть локально

Двойной клик по `index.html`. Всё работает офлайн: шрифты системные, внешних запросов нет.

Если нужен локальный сервер:

```powershell
cd MEDIKA
python -m http.server 8000
# http://localhost:8000
```

## Личный кабинет (демо)

Данные хранятся в `localStorage` браузера, сервер не нужен.

- Вход: любой телефон (от 10 цифр) или e-mail, код — **1234**.
- Кнопка «Войти в демо-кабинет» пускает сразу.
- В кабинете: отмена записи, скачивание результатов (имитация), правка профиля.
- Выход — в левом меню; после выхода `account.html` перекидывает на `login.html`.

## Что работает

- **Адаптивность** — контрольные точки 1120 / 980 / 720 / 420 px, мобильное меню-drawer.
- **Запись** — направление подгружает врачей профиля, календарь строит 12 ближайших дат (кроме воскресений), слоты 09:00–19:30, занятые недоступны, панель итога обновляется на ходу.
- **Предзаполнение** — `appointment.html?doctor=sokolova` или `?spec=cardiology`.
- **Поиск и фильтры** в прайсе работают вместе, поддерживается `services.html?q=ЭКГ`.
- **Формы** — маска `+7 (___) ___-__-__`, проверка полей и e-mail, экран «Заявка принята».
- **Доступность** — skip-link, aria-атрибуты, видимый фокус, `prefers-reduced-motion`.

## Опубликовать

### Cloudflare Pages — бесплатно, без кредитов (рекомендую)

Через панель:

1. `dash.cloudflare.com` → **Workers & Pages** → **Create**
2. Вкладка **Pages** → **Upload assets**
3. Имя проекта: `medika-clinic`
4. Перетащить **папку `MEDIKA`** целиком → **Deploy site**
5. Адрес `https://medika-clinic.pages.dev` появится через ~20 секунд

Или запустить `deploy-cloudflare.cmd` — сам загрузит и напечатает ссылку.

### Netlify

`deploy-netlify.cmd` либо перетащить папку на `app.netlify.com/drop`.

Нужен остаток кредитов на аккаунте: при сообщении **«Account credit usage exceeded»** публикация блокируется на стороне Netlify — ни папка, ни архив не помогут, только пополнение или месячный сброс.

### GitHub Pages

Содержимое папки в репозиторий → Settings → Pages → Branch `main`, папка `/root`.

### Про деплой

- `_headers` и `404.html` поддерживаются и Netlify, и Cloudflare Pages — настраивать ничего не нужно.
- Папку `_sources` можно удалить перед загрузкой: она не влияет на сайт, просто не будет 14 МБ исходников в деплое.

## Важно

Клиника «МЕДИКА», врачи, отзывы, адреса, лицензия, результаты анализов и назначения — **вымышленные**, сайт демонстрационный. Кабинет хранит данные только в браузере. Перед реальным использованием замените контакты и юридические данные, добавьте политику обработки персональных данных, подключите формы и авторизацию к серверу.

## Версия для слабовидящих

Кнопка с иконкой глаза в шапке каждой страницы. Открывает панель настроек:

- **размер шрифта** — три ступени (100 / 115 / 130 %);
- **цветовая схема** — чёрным по белому, белым по чёрному, синим по голубому, коричневым по бежевому;
- **изображения** — показывать или скрыть;
- **межбуквенный интервал** — обычный или увеличенный;
- **«Обычная версия сайта»** — сброс.

Выбор сохраняется в `localStorage` и применяется до отрисовки страницы, поэтому режим не «мигает» при переходе между страницами. Разметка панели генерируется скриптом, кнопки имеют `aria-pressed`, панель закрывается по Esc.

Файлы: `assets/css/a11y.css`, `assets/js/a11y.js`.
